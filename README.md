# Punkt B Dashboard

</div>

A commercial project developed for **Punkt B**, an international online career guidance school: a dashboard for career consultants within the school's website.

The dashboard combines career assessments, client database management, and personalized career recommendations in a single workspace.

By automating key processes, the dashboard significantly reduced routine administrative work, accelerated assessment processing, and improved the quality of client support.

## ✨ Features

- User authentication and personal profiles
- Client database management
- Career assessments and results analysis
- Specialist management and access control
- Personalized career recommendations with PDF report generation and export

## 📌 Project Overview

- **Project Type:** Commercial
- **Development Period:** 2023-2025
- **Role:** Frontend Developer
- **Team:** Designer, Product Manager, Backend Developer
- **Core Technologies:** JavaScript, jQuery, REST API

## 👨‍💻 Responsibilities

### April 2023

- Developed the user dashboard and administrative panel
- Designed and implemented interfaces for completing [career assessments](#assessment), collecting their results, and analyzing them
- Built search, filtering, and navigation tools for assessment results
- Developed the mobile version of the platform
- Integrated external services via REST API
- Collaborated closely with the designer, product manager, and backend developer in a cross-functional team
- Performed code reviews, fixed bugs, and maintained the product

### January 2024

- Developed the [report generation module](#conclusion)
- Implemented personalized PDF report generation and export

### October 2025

- Led a complete architectural redesign of the platform
- Refactored core modules to improve performance, scalability, and maintainability

## 📈 Key Results

- Reduced the time specialists spend working with clients by **30%**
- **Doubled** the speed of assessment completion and result processing through UI improvements
- Automated the generation of personalized career reports
- Improved platform stability and maintainability through architectural refactoring

## 🛠️ Technologies

### Frontend

- **HTML**

- **JavaScript**
- **jQuery**
- **Moment.js**

### Integrations

- **REST API**

### Infrastructure

- Migrated the project from Tilda to a dedicated hosting environment
- Continued platform support and feature development after migration
