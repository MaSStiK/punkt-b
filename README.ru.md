# Личный кабинет для профориентологов внутри сайта Пункт Б

</div>

Коммерческий проект для международной онлайн-школы выбора профессии **«Пункт Б»**.

«Пункт Б» - внутренняя платформа для профориентологов, которая объединяет проведение диагностик, управление клиентской базой и подготовку персональных карьерных рекомендаций в едином рабочем пространстве.

Автоматизация ключевых процессов позволила заметно сократить рутинную административную работу, ускорить обработку диагностик и повысить качество работы с клиентами.

## ✨ Возможности

- Аутентификация пользователей и личные профили
- Управление клиентской базой
- Проведение профориентационных диагностик и анализ результатов
- Управление специалистами и правами доступа
- Персональные карьерные рекомендации с генерацией и экспортом PDF-заключений

## 📌 Кратко о проекте

- **Тип проекта:** Коммерческий
- **Период разработки:** 2023-2025
- **Роль:** Разработчик клиентской части
- **Команда:** Дизайнер, менеджер продукта, разработчик серверной части
- **Основные технологии:** JavaScript, jQuery, REST API

## 👨‍💻 Моя роль в проекте

### Апрель 2023

- Разработал личный кабинет пользователя и административную панель
- Спроектировал и реализовал интерфейсы для прохождения [профориентационных диагностик](#assessment), сбора и анализа их результатов
- Реализовал поиск, фильтрацию и навигацию по результатам диагностик
- Разработал мобильную версию платформы
- Интегрировал внешние сервисы через REST API
- Тесно сотрудничал с дизайнером, менеджером продукта и разработчиком серверной части в кросс-функциональной команде
- Проводил ревью кода, исправлял ошибки и поддерживал продукт

### Январь 2024

- Разработал [модуль формирования заключений](#conclusion)
- Реализовал генерацию и экспорт персонализированных PDF-заключений

### Октябрь 2025

- Руководил полной переработкой архитектуры платформы
- Выполнил рефакторинг ключевых модулей для повышения производительности, масштабируемости и удобства дальнейшей поддержки

## 📈 Результаты

- Сократил время работы специалистов с клиентами на **30%**
- Ускорил прохождение диагностик и обработку результатов **в 2 раза** благодаря улучшению пользовательского интерфейса
- Автоматизировал формирование индивидуальных профориентационных заключений
- Повысил стабильность и удобство поддержки платформы благодаря архитектурному рефакторингу
